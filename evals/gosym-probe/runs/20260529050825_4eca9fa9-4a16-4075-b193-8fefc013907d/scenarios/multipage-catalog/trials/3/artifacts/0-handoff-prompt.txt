Build a multi-page website for "Artisan Goods Co.", a handmade crafts shop. Full site build — not just a homepage preview.

PROJECT DETAILS:
- Business: Artisan Goods Co. — handmade crafts shop
- Categories: Pottery, Textiles, Woodwork, Jewelry
- Audience: Craft lovers, gift shoppers, design-conscious consumers
- Goal: Showcase products, tell brand story, capture newsletter leads

DESIGN DIRECTION:
Warm, artisanal aesthetic that feels handcrafted and authentic — like browsing a well-curated local market. Rich earthy tones with generous whitespace and tactile-feeling typography. NOT a generic e-commerce template.

LAYOUT TYPE: Standard
Full header navigation and footer across all pages.

VISUAL DIRECTION:
- Color: Warm earthy palette — terracotta, warm cream/off-white, deep walnut brown, sage green accent. No pure white or cold grays.
- Typography: Elegant serif for headings (e.g. Playfair Display or Lora) paired with a clean humanist sans for body (e.g. Source Sans Pro or Nunito). Generous line-height.
- Layout: Asymmetric product grids, full-bleed hero imagery, editorial section breaks. NO uniform icon grids or centered-text-on-colored-band CTAs.
- Visual elements: Photography-forward (product shots, artisan at work). Subtle organic texture overlays on section backgrounds.
- Motion: Subtle — fade-in on scroll for product cards (staggered), gentle hover lift on cards (translate-y + shadow), smooth filter transitions.

LOGO:
Use the media-logo skill to generate a logo for "Artisan Goods Co." — warm, handcrafted feel with a simple mark (e.g. a pottery wheel or leaf motif). Place in header and footer.

MOTION DESIGN:
- Level: Subtle
- Effects: Staggered fade-in on product cards (scroll-triggered, 300ms each, 80ms stagger), hover lift on cards (translateY -4px + shadow deepens, 200ms ease-out), smooth category filter tab transitions, newsletter input focus glow
- Personality: Warm and unhurried — nothing snappy or corporate

BUILD ORDER:

Phase 1 — Setup (run in parallel):
- Search for images: artisan pottery hero, handmade textiles, woodwork products, jewelry flatlay, team/workshop photos
- Set font stack using fontTheme tool: Playfair Display (headings) + Source Sans Pro or similar (body)
- Set color scheme using colorScheme tool: terracotta primary, warm cream background, walnut brown foreground, sage green accent
- Generate logo using media-logo skill

Phase 2 — Structure (run in parallel, after Phase 1):
- Build Header (src/layouts/parts/Header.tsx): logo left, nav links (Home, Shop, About), clean professional style with warm colors. Mobile hamburger menu.
- Build Footer (src/layouts/parts/Footer.tsx): multi-column — logo + tagline, nav links, newsletter micro-CTA, social icons. Warm earthy feel matching hero.

Phase 3 — API (after Phase 1):
- Create src/server/api/products.ts: Express handler for GET /api/products. Returns array of 12 products across 4 categories (pottery, textiles, woodwork, jewelry). Each product: { id, name, category, price, description, imageQuery }. Register in src/server/entry.ts.

Phase 4 — Pages (after Phase 1, 2, and 3 are complete):

HOMEPAGE (src/pages/index.tsx):
- Hero: Full-bleed image (artisan workshop/pottery), large serif headline "Handcrafted with Care", subheadline, two CTAs (Shop Now → /shop, Our Story → /about). Text overlaid with warm gradient. Subtle entrance animation.
- Featured Products: "Our Favorites" section — 4 featured product cards in asymmetric grid (one large, three smaller). Cards show image, name, category badge, price. Staggered fade-in on scroll. Fetch from /api/products (use useEffect, not loader — client-side is fine for homepage featured).
- Newsletter signup: Warm-toned section with serif headline "Join Our Community", email input + subscribe button. NOT a centered-on-colored-band — use an asymmetric layout with a decorative organic shape or texture.
- DO NOT use icon grids anywhere.

PRODUCT CATALOG PAGE (src/pages/shop.tsx):
- Use a React Router loader to fetch from /api/products (SSR-friendly, products need to be indexed).
- Category filter tabs: All | Pottery | Textiles | Woodwork | Jewelry — styled as pill tabs, smooth active state transition.
- Product grid: responsive (1 col mobile, 2 col tablet, 3-4 col desktop). Cards: product image (aspect-ratio 4/3), name, category badge, price, subtle "View Details" hover reveal. Staggered entrance animation.
- Filter state managed client-side (filter the already-loaded data, no re-fetch).
- Page title: "The Shop" with a short editorial subheadline.

ABOUT PAGE (src/pages/about.tsx):
- Mission statement: Large pull-quote style, serif, prominent. E.g. "We believe every object should tell a story."
- Our Story: Two-column editorial layout — text left, artisan workshop photo right. Warm, personal tone.
- Team profiles: 3 team members in a row. Each: circular photo, name, role, short bio. Warm card style.
- Values section: 3 values (e.g. Sustainability, Craftsmanship, Community) — NOT icon cards. Use large typographic numbers or decorative text treatment instead.
- Page uses static content (no API needed).

ROUTES (src/routes.tsx):
Add routes for /, /shop, /about. The /shop route needs a loader that calls fetch('/api/products') and returns the data.

DIFFERENTIATION:
The asymmetric featured products grid on the homepage (one large hero card + three smaller) creates immediate visual interest. The editorial two-column About layout feels like a magazine, not a template.

CONSISTENCY:
Warm earthy palette and serif/sans pairing must be consistent across all three pages. Footer should feel as intentional as the hero. Card hover effects identical on homepage featured and shop grid.
