Build a multi-page website for "Artisan Goods Co.", a handmade crafts shop. Full site — not just a homepage preview.

PROJECT DETAILS:
- Business: Artisan Goods Co. — handmade crafts shop
- Categories: Pottery, Textiles, Woodwork, Jewelry
- Pages: Homepage, Product Catalog, About

DESIGN DIRECTION:
Warm, artisanal aesthetic that feels handcrafted and authentic — like a well-curated maker's market. Rich earthy tones with generous whitespace and editorial typography. Should feel premium and personal, not mass-market.

LAYOUT TYPE: Standard
Multi-page site with shared navigation header and footer across all pages.

VISUAL DIRECTION:
- Color: Warm earthy palette — terracotta, warm cream/off-white, deep walnut brown, and a sage green accent. NOT generic white + gray.
- Typography: Serif display font for headings (warmth, craft heritage), clean sans-serif for body. Mix weights confidently.
- Layout: Asymmetric compositions, full-bleed imagery sections, bento-style product grid with varied card sizes on homepage featured section.
- Visual elements: Photography-forward (actual product images). Subtle organic texture accents (grain overlays, soft dividers).
- Motion: Subtle — fade-in on scroll for sections, gentle hover lifts on product cards (translate-y + shadow), smooth button transitions.

LOGO:
Use the media-logo skill to generate a logo for "Artisan Goods Co." — a refined mark that feels handcrafted and artisanal. Place in header and footer.

SECTION-SPECIFIC GUIDANCE:

Hero (Homepage):
- Full-bleed hero with a warm lifestyle/craft photography image
- Headline: oversized serif type, grid-breaking scale
- Subheadline and CTA button ("Shop Now" → links to /products)
- Subtle fade-in entrance animation

Featured Products (Homepage):
- Bento-style grid with varied card sizes (NOT uniform 3-col icon grid)
- Show 4–6 featured products fetched from API
- Cards: product image, name, price, hover lift effect
- "View All" link to /products

Newsletter Signup (Homepage):
- Warm, integrated section — NOT a centered-on-colored-band CTA
- Asymmetric layout with a decorative element
- Email input + subscribe button
- Subtle hover/focus states

Product Catalog Page (/products):
- Category filter tabs: All, Pottery, Textiles, Woodwork, Jewelry
- Products fetched from /api/products?category=X
- Responsive grid of product cards (image, name, price)
- Hover lift on cards
- Loading skeleton state while fetching
- Empty state if no products in category

About Page (/about):
- Brand story section with full-bleed or large imagery
- Mission statement — typographically prominent, pull-quote style
- Team member profiles: photo, name, role, short bio (3–4 members)
- Warm, editorial layout — NOT a generic "three columns of headshots"

Header:
- Logo left, navigation right: Home, Products, About
- Clean, professional style with generous vertical padding (~80–100px desktop)
- Active route highlighted
- Mobile-responsive hamburger menu

Footer:
- Multi-column: brand/tagline, navigation links, social icons
- Maintain warm earthy design language — not an afterthought
- Copyright line

DIFFERENTIATION:
Oversized serif typography in the hero that breaks the grid. Bento product grid on homepage. The overall warmth and texture should feel unlike any generic e-commerce template.

CONSISTENCY:
Maintain earthy warmth throughout all three pages and the footer. Animation style consistent — gentle, never jarring.

BUILD ORDER:

Phase 1 — Setup (run in parallel):
- Search for images: hero lifestyle/craft image, product images for each category (pottery, textiles, woodwork, jewelry), team member photos
- Set font stack using fontTheme tool — serif display + clean sans-serif pairing

- Generate logo using media-logo skill

Phase 2 — API + Structure (run in parallel after Phase 1):
- Build Express API endpoint: GET /api/products — returns array of products with id, name, category, price, image. Include 12–16 mock products across all 4 categories. Support ?category= query param for filtering.

Phase 3 — Pages (after Phase 1 & 2):

Phase 4 — Routes + Finalize:
