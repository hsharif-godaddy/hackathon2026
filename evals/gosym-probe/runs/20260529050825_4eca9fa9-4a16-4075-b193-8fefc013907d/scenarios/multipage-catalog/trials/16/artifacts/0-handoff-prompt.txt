Build a multi-page website for "Artisan Goods Co.", a handmade crafts shop. Full site build — not just a homepage preview.

PROJECT DETAILS:
- Business: Artisan Goods Co. — handmade crafts shop
- Categories: Pottery, Textiles, Woodwork, Jewelry
- Audience: Craft lovers, gift shoppers, artisan enthusiasts
- Goal: Showcase products, tell the brand story, capture newsletter signups

DESIGN DIRECTION:
Warm, artisanal, and editorial. Should feel like a premium handmade brand — think natural textures, earthy tones, and generous whitespace. Confident and inviting without being rustic or kitschy.

LAYOUT TYPE: Standard
Multi-page site with shared header and footer navigation.

VISUAL DIRECTION:
- Color: Warm earthy palette — warm cream/off-white background, terracotta accent, deep charcoal text, sage green secondary. NOT generic white + black.
- Typography: Elegant serif for headings (Playfair Display or similar), clean sans-serif for body (DM Sans or similar). Mix weights with confidence.
- Layout: Editorial asymmetry. Hero is full-bleed with overlaid text. Product grid uses varied card sizes. NO centered-text-on-colored-band CTAs.

VISUAL ELEMENTS:
- Primary: Photography (product shots, artisan at work, natural materials)
- Style: Warm, natural lighting — wood surfaces, linen textures, earthy tones
- Application: Full-bleed hero, product card images, team member photos on About page
- Logo: Generate a wordmark logo using the media-logo skill — elegant serif "Artisan Goods Co." with a small hand-crafted icon accent

MOTION DESIGN:
- Level: Subtle
- Effects: Fade-in on scroll for product cards (staggered, 300ms), hover lift on product cards (translate-y + shadow), smooth page transitions, gentle hover underline on nav links
- Personality: Warm and refined — nothing bouncy or jarring

SECTION-SPECIFIC:

Hero (Homepage):
- Full-bleed image with warm overlay, headline overlaid on image
- Subheadline and two CTAs (Shop Now → /products, Our Story → /about)
- Subtle fade-in entrance animation

Featured Products (Homepage):
- Section title + 4 featured products pulled from API
- Asymmetric grid (one large card + three smaller), NOT uniform 4-column
- Hover lift effect on cards

Newsletter Signup (Homepage):
- Warm, integrated section — NOT a colored band
- Email input + subscribe button, simple and elegant
- No backend needed — just UI with a success state

Product Catalog Page (/products):
- Fetch from GET /api/products?category=all (or filtered)
- Category filter tabs: All, Pottery, Textiles, Woodwork, Jewelry
- Responsive product grid (3 columns desktop, 2 tablet, 1 mobile)
- Each card: image, name, category badge, price
- Loading skeleton state while fetching

About Page (/about):
- Hero section with mission statement (large, editorial typography)
- Brand story section (2-column: text left, image right)
- Team member profiles: 3 members, photo + name + role + short bio
- Values/mission statement section with 3 key values

Header:
- Logo left, nav links center/right: Home, Shop, About
- Sticky on scroll with subtle background blur
- Mobile hamburger menu

Footer:
- 3-column: brand blurb + nav links + social icons
- Warm, intentional design matching overall aesthetic

DIFFERENTIATION:
Oversized serif headline in hero that breaks the grid. Product cards use a warm hover state (terracotta border glow) rather than generic shadow lift alone.

CONSISTENCY:
Maintain warm, editorial quality throughout — footer as intentional as hero. Staggered card animations consistent across homepage and catalog.

BUILD ORDER:

Phase 1 — Setup (run in parallel):
- Search for images: hero (artisan workshop/handmade goods), product shots for each category (pottery, textiles, woodwork, jewelry), team member portraits
- Set font stack using fontTheme tool: elegant serif (Playfair Display) + clean sans (DM Sans)
- Set color scheme using colorScheme tool: warm cream background, terracotta primary, charcoal foreground, sage secondary
- Generate logo using media-logo skill

Phase 2 — API + Structure (run in parallel after Phase 1):
- Build Express API endpoint: GET /api/products — returns array of products with id, name, category, price, image, description. Include 12 products across 4 categories. Support ?category= query param for filtering.
- Build Header (src/layouts/parts/Header.tsx): sticky, blur on scroll, logo + nav links + mobile menu
- Build Footer (src/layouts/parts/Footer.tsx): 3-column warm footer

Phase 3 — Pages (after Phase 1 & 2):
- Add routes in routes.tsx: / (homepage), /products (catalog), /about
- Build Homepage (src/pages/index.tsx): hero + featured products (fetch from API) + newsletter signup
- Build Product Catalog (src/pages/products.tsx): category filters + product grid fetched from API with loading skeletons
- Build About page (src/pages/about.tsx): mission hero + brand story + team profiles + values
