Build a multi-page website for "Artisan Goods Co.", a handmade crafts shop. Full details below.

PROJECT DETAILS:
- Business: Artisan Goods Co. — handmade crafts shop
- Categories: Pottery, Textiles, Woodwork, Jewelry
- Pages: Homepage, Product Catalog, About

DESIGN DIRECTION:
Warm, artisanal aesthetic that feels handcrafted and authentic — like a well-curated maker's market. Earthy and inviting, not corporate or generic. Rich textures implied through typography and color, not stock imagery clichés.

LAYOUT TYPE: Standard
Multi-page marketing/shop site with shared header and footer navigation.

VISUAL DIRECTION:
- Color: Warm earthy palette — deep terracotta, warm cream/off-white, warm brown, and a muted sage green accent. No pure white or cold grays.
- Typography: Serif display font for headings (warmth, craftsmanship feel) paired with a clean humanist sans-serif for body. Generous line-height.
- Layout: Asymmetric sections with full-bleed imagery. NO uniform icon grids. Product grid uses varied card proportions. Staggered layouts for team profiles.
- Visual elements: Warm photography of handmade goods and craft process. Organic texture accents (subtle grain or paper-like backgrounds on sections). No generic stock photo vibes.
- Motion: Subtle — fade-in on scroll for sections, gentle hover lifts on product cards (translate-y + shadow), smooth button transitions.

LOGO:
Use the media-logo skill to generate a logo for "Artisan Goods Co." — a refined, handcrafted mark. Style: simple botanical or craft tool motif, warm terracotta/brown tones. Place in header top-left.

MOTION DESIGN:
- Level: Subtle
- Effects: Fade-in on scroll (350ms ease-out), hover lift on product cards (translateY -4px + shadow deepens, 200ms), smooth nav link underline draw on hover
- Personality: Warm and unhurried — nothing snappy or corporate

SECTION-SPECIFIC:

Hero (Homepage):
- Full-bleed warm lifestyle image (search for artisan/handmade goods hero)
- Headline overlaid with semi-transparent warm overlay (NOT a plain colored band)
- Subheadline + dual CTAs: "Shop Now" → /products, "Our Story" → /about
- Staggered fade-in entrance animation

Featured Products (Homepage):
- Pull 4 featured products from the API (/api/products?featured=true)
- Asymmetric bento-style grid (2 large + 2 small cards), NOT a uniform 4-column grid
- Each card: product image, name, price, category tag, hover lift effect
- "View All Products" link below

Newsletter Signup (Homepage):
- Integrated section with warm background (terracotta or cream), NOT a generic centered-on-band CTA
- Asymmetric layout: headline left, form right
- Email input + subscribe button with hover animation

Product Catalog Page (/products):
- Route loader fetches all products from /api/products
- Category filter tabs (All, Pottery, Textiles, Woodwork, Jewelry) — pill-style, not dropdown
- Responsive product grid (3 cols desktop, 2 tablet, 1 mobile)
- Each card: image, name, price, category badge, hover lift
- Filter state managed with React useState (client-side filter of loaded data)

About Page (/about):
- Hero section: mission statement in large serif type, warm background
- Brand story: 2-column layout (text left, lifestyle image right), full narrative paragraphs
- Team profiles: staggered asymmetric grid (NOT uniform 3-column), each with photo, name, role, short bio
- Search for artisan/team portrait photos

Shared Header (src/layouts/parts/Header.tsx):
- Style: Professional with artisan warmth
- Logo left, nav links right: Home, Shop, About
- Warm cream/off-white background, terracotta accent on active/hover
- Sticky on scroll with subtle shadow on scroll
- Mobile hamburger menu

Shared Footer (src/layouts/parts/Footer.tsx):
- Multi-column: Brand tagline left, nav links center, newsletter micro-form right
- Warm brown background, cream text
- Social links (Instagram, Pinterest — fitting for artisan brand)
- Copyright line

PRODUCTS API (src/server/api/products.ts):
Create an Express API endpoint at GET /api/products that returns mock product data. Register it in src/server/entry.ts.

Product schema:
```ts
{
  id: string,
  name: string,
  price: number,
  category: "pottery" | "textiles" | "woodwork" | "jewelry",
  image: string, // use placeholder or Getty search
  featured: boolean,
  description: string
}
```

Include 12 mock products (3 per category), with 4 marked featured: true.
Support query param ?featured=true to filter.

ROUTES (src/routes.tsx):
- / → Homepage (index.tsx) with loader fetching /api/products?featured=true
- /products → ProductCatalog page with loader fetching /api/products
- /about → About page (static, no loader needed)

DIFFERENTIATION:
Bento-style featured products grid on homepage breaks the uniform-grid cliché. Serif + earthy palette creates genuine artisan warmth rather than generic "handmade" template feel.

CONSISTENCY:
Maintain earthy warmth throughout — footer as intentional as hero. Terracotta accent consistent across CTAs, category badges, hover states. Serif headings used consistently at every level.
