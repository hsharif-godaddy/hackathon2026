Build a multi-page website for "Artisan Goods Co.", a handmade crafts shop. Full details below.

PROJECT DETAILS:
- Business: Artisan Goods Co. — handmade crafts shop
- Categories: Pottery, Textiles, Woodwork, Jewelry
- Pages: Homepage, Product Catalog, About

DESIGN DIRECTION:
Warm, artisanal aesthetic that feels handcrafted and authentic — like stepping into a beloved local market. Rich earthy tones with generous whitespace and editorial typography that honors the craft behind every product. Avoid anything that feels corporate or mass-produced.

LAYOUT TYPE: Standard
Multi-page site with shared header navigation and footer.

VISUAL DIRECTION:
- Color: Warm earthy palette — terracotta, warm cream/off-white, deep walnut brown, sage green accent. No pure whites or cold grays.
- Typography: Elegant serif for headings (warmth, craft heritage), clean readable sans-serif for body. Generous line-height and letter-spacing.
- Layout: Full-bleed hero with product photography. Staggered product grid (not uniform rows). Asymmetric about page layout.

VISUAL ELEMENTS:
- Primary: Photography — product shots with natural lighting, warm textures
- Style: Authentic, natural-light product photography feel
- Application: Hero full-bleed, product cards with square-crop images, team photos in circular frames
- Logo: Use media-logo skill to generate a logo — warm wordmark style with a subtle hand-drawn or artisan feel

MOTION DESIGN:
- Level: Subtle
- Effects: Fade-in on scroll for product cards (staggered, 300ms), hover lift on product cards (translate-y -4px + shadow), smooth nav link underline draw on hover
- Personality: Warm and unhurried — gentle reveals, nothing jarring

SECTION-SPECIFIC:

Hero (Homepage):
- Full-bleed background image, warm overlay gradient
- Large serif headline: "Handcrafted with Love"
- Subheadline + two CTAs: "Shop Now" → /products, "Our Story" → /about
- Subtle fade-in entrance animation

Featured Products (Homepage):
- Section title: "Featured Pieces"
- Show 4 featured products in a 2×2 or 4-col grid
- Each card: product image, name, category badge, price, hover lift animation
- "View All" link to /products

Newsletter Signup (Homepage):
- Warm-toned section (terracotta background)
- Headline: "Join Our Community"
- Email input + subscribe button
- NOT a centered-on-band generic CTA — use asymmetric layout with decorative element

Product Catalog (/products):
- Category filter tabs/pills: All, Pottery, Textiles, Woodwork, Jewelry
- Responsive product grid (3-col desktop, 2-col tablet, 1-col mobile)
- Each card: image, name, category, price
- Products fetched from /api/products (with optional ?category= query param)
- Loading skeleton state while fetching
- Staggered card entrance animation

About Page (/about):
- Hero: Full-width banner with brand story headline
- Mission statement: Large pull-quote style, serif font, centered with generous padding
- Our Story: Two-column layout — text left, image right (asymmetric)
- Team section: Grid of team member cards with circular photo, name, role, short bio
- Team data can be hardcoded (3-4 members)

Header:
- Logo left, nav links right: Home, Shop, About
- Sticky on scroll with subtle background blur
- Mobile hamburger menu
- Active link indicator

Footer:
- Three columns: brand blurb + logo, quick links, newsletter micro-form
- Warm background (dark walnut or deep terracotta)
- Copyright line

BUILD ORDER:

Phase 1 — Setup (run in parallel):
- Search for images: artisan pottery products, handmade textiles, woodwork crafts, jewelry, hero lifestyle shot of craft workshop, team/people photos
- Set font stack using fontTheme tool — serif display font (e.g. Playfair Display or similar) + clean sans body
- Set color scheme using colorScheme tool — terracotta primary, warm cream background, walnut dark, sage accent
- Generate logo using media-logo skill

Phase 2 — API + Structure (run in parallel after Phase 1):
- Build Express API endpoint: GET /api/products — returns array of 12 products across 4 categories (pottery, textiles, woodwork, jewelry). Each product: { id, name, category, price, image, featured: boolean }. Support ?category= filter. Use real Getty image searches for product images.
- Build Header.tsx — sticky nav with logo, links, mobile menu
- Build Footer.tsx — three-column warm footer

Phase 3 — Pages (after Phase 2):
- Build Homepage (index.tsx): hero, featured products (fetch from API with featured=true or first 4), newsletter section
- Build Product Catalog page (src/pages/products.tsx): category filters, product grid, fetches from /api/products
- Build About page (src/pages/about.tsx): hero, mission, story, team grid

Phase 4 — Routes + Finalize:
- Add routes in routes.tsx: / → index, /products → products page, /about → about page
- Mark all todo items as COMPLETE using the todoList tool
- Ask for design feedback using askQuestion

CRITICAL BUILD NOTES:
- Products MUST be fetched from /api/products endpoint (not hardcoded in components)
- Use React Router for all navigation (Link component, no anchor tags)
- Use route loaders for the product catalog page so products are SSR'd
- Add loading skeletons for product grid while data loads
- All pages need Helmet title/description tags
- Keep animation consistent — same easing and duration across all card hovers
