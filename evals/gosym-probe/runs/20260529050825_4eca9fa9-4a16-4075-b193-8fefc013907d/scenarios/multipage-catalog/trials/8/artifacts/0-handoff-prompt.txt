Build a complete multi-page website for "Artisan Goods Co.", a handmade crafts shop. This is a full build — not just a homepage preview — covering all pages listed below.

PROJECT DETAILS:
- Business: Artisan Goods Co. — handmade crafts shop
- Categories: Pottery, Textiles, Woodwork, Jewelry
- Pages needed: Homepage, Product Catalog, About
- Data: Products fetched from an Express API endpoint

DESIGN DIRECTION:
Warm, artisanal aesthetic that feels handcrafted and authentic — like a beloved local market stall elevated to a premium boutique. Rich earthy tones with generous whitespace. Photography-forward with organic textures. Should feel inviting and trustworthy, not corporate or generic.

LAYOUT TYPE: Standard
Full header navigation and footer across all pages.

VISUAL DIRECTION:
- Color: Warm earthy palette — terracotta, warm cream/off-white, deep walnut brown, sage green accent. NOT stark white or generic blue. Warm off-white (#FAF7F2 range) as base background.
- Typography: Elegant serif for headings (Playfair Display or similar), clean humanist sans for body (Lato or similar). Generous line-height, warm and readable.
- Layout: Full-bleed hero with warm overlay. Product grid with generous spacing. NO icon grids. Asymmetric section layouts where possible.
- Visual elements: Photography-forward. Use Getty stock images for hero (artisan workshop, handmade pottery, textiles), product cards, and team photos. Subtle organic texture overlays.
- Motion: Subtle — fade-in on scroll for sections, gentle hover lift on product cards (translate-y + shadow), smooth nav transitions.

LOGO:
Use the media-logo skill to generate a logo for "Artisan Goods Co." — a warm, handcrafted mark with artisan feel. Place in header and footer.

MOTION DESIGN:
- Level: Subtle
- Effects: Fade-in on scroll (400ms ease-out), hover lift on product cards (translateY -4px + shadow deepens, 200ms), smooth underline hover on nav links, newsletter button hover fill (200ms)
- Personality: Warm and unhurried — nothing snappy or corporate

SECTION-SPECIFIC:

Hero (Homepage):
- Full-bleed image of an artisan workshop or handmade goods with warm gradient overlay
- Headline: "Crafted with Care, Made to Last" — large serif, warm cream color

- Warm background section (terracotta or deep brown)

- Responsive product grid (3 cols desktop, 2 tablet, 1 mobile)
- Each card: product image, name, category badge, price
- Products fetched from /api/products?category={category} (or all if no filter)

Shared Header:

Shared Footer:
- Multi-column: Brand blurb + logo | Navigation links | Contact info
- Warm dark background (deep walnut/charcoal brown)

- Social icons (Instagram, Pinterest, Facebook — artisan brands)

DIFFERENTIATION:
Full-bleed photography sections with warm gradient overlays that break the vertical rhythm. Serif/sans type pairing creates editorial feel. Product cards with category color-coded badges.

CONSISTENCY:
Maintain warm artisanal energy throughout — footer and about page must feel as intentional as the homepage hero. No design energy drop-off.

API SHAPE (src/server/api/products.ts, imported + registered in src/server/entry.ts):
```ts
GET /api/products
  ?category=pottery|textiles|woodwork|jewelry  (optional)
  ?featured=true  (optional)
Response: { products: Product[] }

Product: {
  id: string,
  name: string,
  category: 'pottery' | 'textiles' | 'woodwork' | 'jewelry',
  price: number,  // e.g. 48.00
  description: string,
  imageUrl: string,
  featured: boolean
}
```
