Build a multi-page website for "Artisan Goods Co.", a handmade crafts shop. Full site — not just a homepage preview.

PROJECT DETAILS:
- Business: Artisan Goods Co. — handmade crafts shop
- Categories: Pottery, Textiles, Woodwork, Jewelry
- Pages needed: Homepage, Product Catalog, About

DESIGN DIRECTION:
Warm, artisanal aesthetic that feels handcrafted and authentic — like a well-curated independent shop. Earthy and inviting, not corporate or generic. Generous whitespace with editorial-quality layout.

LAYOUT TYPE: Standard
Multi-page marketing + e-commerce site. Full header with navigation and footer.

VISUAL DIRECTION:
- Color: Warm neutrals — cream/off-white background, warm terracotta or clay as primary accent, deep espresso brown for text. Avoid pure white or cold grays.
- Typography: Serif display font for headings (warmth, craft heritage feel), clean sans-serif for body. Mix weights with confidence — large editorial headings.
- Layout: NO uniform icon grids. Use asymmetric product card layouts, full-bleed hero imagery, editorial section compositions.

VISUAL ELEMENTS:
- Primary: Photography (product shots, artisan hands at work, studio/workshop scenes)
- Style: Warm-toned, natural lighting, authentic craft aesthetic
- Application: Full-bleed hero, product cards with image-forward layout, team profile photos on About page
- Logo: Wordmark-style logo with a subtle craft motif (e.g. a small leaf, hand, or loom icon). Use the media-logo skill to generate it. Place in header top-left.

MOTION DESIGN:
- Level: Subtle
- Effects: Fade-in on scroll for product cards (staggered, 300ms), gentle hover lift on product cards (translate-y-1 + shadow), smooth underline hover on nav links, newsletter button hover fill
- Personality: Warm and unhurried — nothing bouncy or jarring

---

BUILD ORDER:

Phase 1 — Setup (run in parallel):
- Search for images: hero banner (artisan workshop/craft studio), product images for each category (pottery bowls, woven textiles, wooden bowls/cutting boards, handmade jewelry), team member portraits
- Set font stack using fontTheme tool — serif display + clean sans-serif pairing
- Set color scheme using colorScheme tool — warm cream background, terracotta accent, espresso text
- Create the Products API endpoint at `/api/products` in `src/server/api/products.ts` and register it in `src/server/entry.ts`. Return an array of 12 products with: id, name, category (pottery|textiles|woodwork|jewelry), price, description, imageUrl (use placeholder or searched image URLs). Also expose `/api/products/featured` returning 4 featured items.

Phase 2 — Structure (run in parallel, after Phase 1):
- Build Header (`src/layouts/parts/Header.tsx`): Wordmark logo left, nav links center/right: Home, Shop, About. Clean, warm aesthetic. Nav links with subtle underline hover. Mobile hamburger menu.
- Build Footer (`src/layouts/parts/Footer.tsx`): Multi-column — brand tagline left, nav links center, social icons right. Warm background matching brand. Copyright line.

Phase 3 — Pages (after Phase 1 & 2, build in parallel):

**Homepage** (`src/pages/index.tsx`):
- Hero: Full-bleed artisan workshop image, large serif headline ("Handcrafted with Care"), subtext, CTA button "Shop Now" linking to /shop. Subtle fade-in entrance.
- Featured Products: 4 product cards fetched from `/api/products/featured` via route loader. Asymmetric grid (not uniform 4-col). Each card: image, name, category badge, price, hover lift effect.
- Newsletter signup: Warm-toned section, email input + subscribe button. NOT a centered-band CTA — use an asymmetric layout with a decorative craft illustration or shape accent.

**Product Catalog** (`src/pages/shop.tsx`):
- Route: `/shop`
- Fetch all products from `/api/products` via route loader
- Category filter tabs: All, Pottery, Textiles, Woodwork, Jewelry — styled as pill/chip filters, not a dropdown
- Product grid: Responsive (1 col mobile, 2 col tablet, 3 col desktop). Each card: product image (aspect-ratio square), name, category, price. Hover lift animation.
- Filter is client-side (filter the loader data, no additional API calls)
- Add to `routes.tsx`

**About page** (`src/pages/about.tsx`):
- Route: `/about`
- Mission statement: Large editorial serif quote/statement at top
- Our Story: 2-column layout — text left, artisan workshop photo right (asymmetric, not centered)
- Team profiles: 3 team members, each with photo, name, role, short bio. Use a horizontal card layout (photo left, text right), not a uniform grid of portrait cards.
- Add to `routes.tsx`

Phase 4 — Finalize:
- Mark all 5 todo items as COMPLETE using the todoList tool
- Ask for feedback using askQuestion

SECTION-SPECIFIC GUIDANCE:
- Hero: Full-bleed image with warm overlay (gray-900/50), large serif headline, NOT empty-right composition
- Featured products: Staggered grid — vary card sizes slightly for editorial feel
- Newsletter: Asymmetric layout, warm terracotta accent, NOT a centered colored band
- Product catalog filters: Pill-style chips, active state uses terracotta accent
- About mission: Oversized serif quote that breaks the grid — this is the differentiation element
- Footer: Warm espresso or dark cream background, NOT an afterthought

DIFFERENTIATION: Oversized mission statement quote on the About page that breaks the grid with large serif type. Also: the newsletter section uses an asymmetric layout with a decorative organic shape accent rather than a standard colored band.

CONSISTENCY: Maintain warm, artisanal energy throughout all pages and the footer. Animation timing consistent (subtle, 300ms). Serif/sans pairing used consistently across all pages.

ROUTES (add to routes.tsx):
- `/` → Homepage (index.tsx) — with loader for featured products
- `/shop` → Shop/Catalog (shop.tsx) — with loader for all products
- `/about` → About (about.tsx)

CRITICAL: Build pages AFTER setup, header, footer, and API are done. This ensures consistent styling and real data.
