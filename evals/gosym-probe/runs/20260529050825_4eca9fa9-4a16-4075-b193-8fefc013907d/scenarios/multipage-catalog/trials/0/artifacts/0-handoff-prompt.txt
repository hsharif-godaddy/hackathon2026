Build a full multi-page website for "Artisan Goods Co.", a handmade crafts shop. Here is the complete design direction and build plan.

PROJECT DETAILS:
- Business: Artisan Goods Co. — handmade crafts shop
- Categories: Pottery, Textiles, Woodwork, Jewelry
- Pages: Homepage, Product Catalog, About

DESIGN DIRECTION:
Warm, artisanal aesthetic that feels handcrafted and authentic. Rich earthy tones with generous whitespace. Should feel like a curated boutique — not a generic e-commerce template. Typography mixes a warm serif for headings with a clean sans-serif for body copy.

LAYOUT TYPE: Standard
Full navigation header and footer across all pages.

VISUAL DIRECTION:
- Color: Warm earthy palette — terracotta, warm cream/off-white, deep walnut brown, sage green accent. NOT pure white or generic blue. Use CSS variables throughout.
- Typography: Warm serif (Playfair Display or similar) for headings — elegant and handcrafted feel. Clean sans-serif (Lato or DM Sans) for body. Mix weights confidently.
- Layout: Asymmetric hero with full-bleed imagery. Product grid uses varied card sizes in a bento-style layout. NO uniform icon grids.
- Visual elements: Photography-forward (artisan product photos, workshop scenes). Subtle organic texture accents.
- Motion: Subtle — fade-in on scroll for sections, hover lift on product cards (translate-y + shadow), smooth button transitions.

LOGO:
Use the media-logo skill to generate a logo for "Artisan Goods Co." — warm, handcrafted style with a simple artisan mark. Place in header top-left.

SECTION-SPECIFIC:

Hero (Homepage):
- Full-bleed hero image (search for artisan workshop / handmade crafts hero image)
- Headline overlaid: "Handcrafted with Care" — large serif, warm cream color
- Subtext and a warm CTA button ("Shop Now" → /products)
- Subtle dark gradient overlay on image for text legibility
- Fade-in entrance animation on text

Featured Products (Homepage):
- Section title: "Featured Pieces"
- Show 4 featured products pulled from the API (flag `featured: true`)
- Bento-style grid: 2 larger cards + 2 smaller — NOT uniform grid
- Each card: product image, name, category badge, price, hover lift effect
- "View All" link to /products

Newsletter Signup (Homepage):
- Warm, integrated section — NOT a centered-on-colored-band pattern
- Asymmetric layout with a decorative organic shape accent
- Email input + subscribe button
- Subtle copy: "Join our community of craft lovers"

Product Catalog Page (/products):
- Page title: "Our Collection"
- Category filter tabs: All | Pottery | Textiles | Woodwork | Jewelry
- Responsive product grid (3 cols desktop, 2 tablet, 1 mobile)
- Each product card: image, name, category badge, price
- Products fetched via route loader from /api/products
- Filter state managed client-side (filter the loaded data)
- Staggered fade-in animation on product cards

About Page (/about):
- Hero section: "Our Story" — full-width with a warm background color (no image needed)
- Mission statement: prominent pull-quote style, large serif italic
- Brand story: 2-column layout, text left, artisan photo right
- Team profiles: 3 team members in a row — circular photo, name, role, short bio
- Search for artisan/craftsperson team photos

Shared Header:
- Logo top-left (use media-logo skill)
- Nav links: Home | Shop | About
- Clean, warm styling — terracotta or walnut brown accent on active link
- Mobile hamburger menu
- Sticky on scroll

Shared Footer:
- Multi-column: Brand blurb | Quick Links | Categories | Contact info
- Warm dark background (deep walnut/charcoal)
- Cream text
- Social icons row

DIFFERENTIATION:
Bento-style featured products grid with varied card sizes creates hierarchy and visual interest. The hero uses full-bleed photography with a warm gradient overlay — editorial feel, not generic e-commerce.

CONSISTENCY:
Maintain warm artisanal energy throughout all pages and the footer. Animation style consistent — subtle fade-ins and hover lifts everywhere.

BUILD ORDER:

Phase 1 — Setup (run in parallel):
- Generate logo using media-logo skill for "Artisan Goods Co."
- Search for images: hero (artisan workshop), product photos (pottery, textiles, woodwork, jewelry), team photos (craftspeople/artisans), about page artisan photo
- Set font theme using fontTheme tool: Playfair Display (headings) + DM Sans (body)
- Set color scheme using colorScheme tool: terracotta primary, warm cream background, walnut brown foreground, sage green accent

Phase 2 — API + Routes setup (after Phase 1):
- Create `src/server/api/products.ts` — Express handler for GET /api/products
  - Returns array of 12 products across 4 categories (pottery, textiles, woodwork, jewelry)
  - Each product: { id, name, category, price, image (use fetched image URLs), description, featured }
  - Mark 4 products as featured: true (one per category)
  - Import and register this handler in `src/server/entry.ts`
- Update `src/routes.tsx` to add /products and /about routes with loaders
  - /products loader: fetch('/api/products') and return { products }
  - /about loader: no data needed, return {}

Phase 3 — Structure (after Phase 1, in parallel):
- Update `src/layouts/parts/Header.tsx` — logo, nav links (Home/Shop/About), sticky, mobile menu, warm styling
- Update `src/layouts/parts/Footer.tsx` — multi-column, dark warm background, cream text

Phase 4 — Pages (after Phase 2 & 3):
- Build `src/pages/index.tsx` — Homepage (hero, featured products, newsletter)
- Build `src/pages/products.tsx` — Product catalog with filters
- Build `src/pages/about.tsx` — About page with story, mission, team

Phase 5 — Finalize:
- Mark all todo items as complete using the todoList tool
- Show the design and ask for feedback

CRITICAL BUILD NOTES:
- Build pages LAST — after API, routes, header, and footer are all done
- Use `useLoaderData()` in products page to get products from the route loader
- Category filtering is client-side: filter the loaded products array by selected category
- All colors via CSS variables — never hard-code hex values
- Use `@dr.pogodin/react-helmet` for page-specific titles on each page
- Product images: use the actual image URLs fetched in Phase 1 — assign them to products in the API handler
