ROUTES (src/routes.tsx):
```tsx
[
  { path: '/', element: <HomePage /> },
  {
    path: '/products',
    element: <ProductsPage />,
    loader: async () => {
      const res = await fetch('/api/products');
      return { products: await res.json() };
    }
  },
  { path: '/about', element: <AboutPage /> }
]
```

API SHAPE (/api/products response):
```json

]
```
