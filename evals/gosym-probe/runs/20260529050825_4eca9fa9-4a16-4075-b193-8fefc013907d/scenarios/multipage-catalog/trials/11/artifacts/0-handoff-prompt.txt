Build a multi-page artisan crafts website with the following complete spec:

PROJECT DETAILS:
- Business: Artisan Goods Co. — handmade crafts shop
- Pages: Homepage, Product Catalog, About
- Audience: Craft lovers, gift shoppers, design-conscious consumers
- Tone: Warm, artisanal, premium handmade aesthetic

DESIGN DIRECTION:
Warm and earthy editorial aesthetic — think natural textures, generous whitespace, and confident typography that feels handcrafted without being rustic. NOT a generic e-commerce template. The design should feel like a curated boutique, not a marketplace.

LAYOUT TYPE: Standard
Full header navigation and footer across all pages.

VISUAL DIRECTION:
- Color: Warm neutrals — cream/off-white base, warm terracotta accent, deep walnut brown for text. Avoid pure white or cold grays.
- Typography: Serif display font for headings (warmth, craftsmanship feel), clean sans-serif for body. Generous line-height and letter-spacing.
- Layout: Editorial — full-bleed hero, asymmetric product grid, staggered team profiles. NO uniform icon grids.

VISUAL ELEMENTS:
- Primary: Photography (product shots, lifestyle, team)
- Style: Warm, natural lighting — earthy tones, textures
- Application: Full-bleed hero image, product card images, team member photos
- Logo: Wordmark-style logo with a small leaf/hand icon — use media-logo skill to generate

MOTION DESIGN:
- Level: Subtle
- Effects: Fade-in on scroll for sections (350ms ease-out), hover lift on product cards (translate-y -4px + shadow), smooth button color transitions (200ms)
- Personality: Warm and unhurried — nothing snappy or corporate

SECTION-SPECIFIC:

Hero (Homepage):
- Full-bleed background image (warm workshop/craft scene)
- Headline overlaid with semi-transparent warm overlay
- Subheadline + CTA button ("Shop Now" → /products)
- Fade-in entrance animation

Featured Products (Homepage):
- Section title "Handpicked for You"
- Grid of 4 featured products pulled from API (first 4 items)
- Product cards: image, name, category badge, price, hover lift effect
- "View All" link to /products

Newsletter Signup (Homepage):
- Warm-toned section, NOT a centered-on-band CTA
- Asymmetric layout: headline left, email input + button right
- Subtle background texture or shape accent

Product Catalog (/products):
- Category filter tabs: All, Pottery, Textiles, Woodwork, Jewelry
- Responsive product grid (3 cols desktop, 2 tablet, 1 mobile)
- Product cards: image, name, category badge, price
- Products fetched from /api/products?category=X
- Loading skeleton state while fetching
- Staggered fade-in on card entrance

About Page (/about):
- Hero section: full-width warm image + "Our Story" headline
- Brand story section: 2-column (text left, image right), asymmetric
- Mission statement: large pull-quote style, centered, serif font, terracotta accent
- Team profiles: 3 members, photo + name + role + short bio, staggered layout (not uniform grid)
- Fade-in on scroll for each section

Footer:
- Multi-column: Logo + tagline | Navigation links | Contact info
- Warm background (dark walnut brown), light text
- Maintain design quality — not an afterthought

DIFFERENTIATION:
Oversized serif headline in the hero that breaks the grid. Product cards use a warm cream background (not white) with subtle border. Team section uses staggered alternating layout (photo left/right alternating) rather than a uniform card grid.

CONSISTENCY:
Warm earthy palette throughout. Serif/sans pairing consistent on every page. Animation timing consistent (350ms). Footer as intentional as hero.

BUILD ORDER:

Phase 1 — Setup (run in parallel):
- Search for images: hero workshop/craft scene, pottery product, textile product, woodwork product, jewelry product, team member photos (x3), about page story image
- Set font stack using fontTheme tool: serif display (e.g. Playfair Display or Lora) + clean sans (e.g. DM Sans or Nunito)
- Set color scheme using colorScheme tool: cream/off-white background, terracotta primary accent, walnut brown for text/footer
- Generate logo using media-logo skill: warm wordmark for "Artisan Goods Co." with small craft/leaf motif

Phase 2 — Structure (run in parallel, after Phase 1):
- Build Header (src/layouts/parts/Header.tsx): logo left, nav links (Home, Shop, About), mobile menu
- Build Footer (src/layouts/parts/Footer.tsx): multi-column warm dark footer

Phase 3 — API (after Phase 1):
- Build Express API endpoint in src/server/api/products.ts
- Register in src/server/entry.ts
- Endpoint: GET /api/products — returns full product list
- Endpoint: GET /api/products?category=pottery|textiles|woodwork|jewelry — filters by category
- Seed with ~12 mock products across 4 categories, each with: id, name, category, price, description, imageUrl (use placeholder or searched images)

Phase 4 — Routes (after Phase 2 & 3):
- Add /products and /about routes to src/routes.tsx

Phase 5 — Pages (after Phase 4, build in parallel):
- Build src/pages/index.tsx — Homepage (hero, featured products via API, newsletter signup)
- Build src/pages/products.tsx — Product catalog (category filters, product grid, API fetch with useEffect)
- Build src/pages/about.tsx — About page (story, mission, team)

Phase 6 — Finalize:
- Mark all todo items as COMPLETE using todoList tool
- Ask for design feedback using askQuestion

CRITICAL BUILD RULES:
