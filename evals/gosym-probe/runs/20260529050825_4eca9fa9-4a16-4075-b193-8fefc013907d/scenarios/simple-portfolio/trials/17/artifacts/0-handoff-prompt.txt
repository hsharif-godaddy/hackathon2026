Build a personal portfolio homepage design preview with this direction:

PROJECT DETAILS:
- Type: Personal portfolio website
- Sections: Hero, About, Contact
- Design feel: Clean, modern, well-spaced

DESIGN DIRECTION:
Refined and confident personal portfolio with generous whitespace and strong typographic hierarchy. Should feel like a senior creative or developer's portfolio — distinctive and personal, not a generic template. Editorial rhythm with purposeful spacing between sections.

LAYOUT TYPE: Standard
This is a portfolio site with full navigation structure.

VISUAL DIRECTION:
- Color: Near-black base (#0f0f0f) with warm off-white text and a single warm amber/gold accent for highlights and hover states. Avoids the cliché dark-mode-with-cyan look.
- Typography: Large, confident serif display font for the hero name (something like Playfair Display or DM Serif Display), paired with a clean geometric sans-serif (DM Sans or Plus Jakarta Sans) for body and nav. Dramatic size contrast between headline and body.
- Layout: Full-viewport hero with name as oversized typographic statement. Sections separated by generous vertical padding. DO NOT use icon grids. DO NOT use centered-text-on-colored-band CTAs.

VISUAL ELEMENTS:
- Primary: Typographic — the design leans on type as the visual element
- Style: Minimal decorative elements — a thin horizontal rule, subtle dot or line accent near the name, possibly a small abstract geometric shape in warm gold
- Application: Accent shapes used sparingly in hero and contact section only
- Logo: No logo needed — name in header as wordmark using the serif display font

MOTION DESIGN:
- Level: Subtle
- Effects:
  - Hero name fades and slides up on load (500ms, easeOut)
  - Tagline follows with slight delay (200ms stagger)
  - About and contact sections fade in on scroll (viewport: once)
  - Nav links have smooth underline-draw hover effect
  - Social icons have gentle scale + color shift on hover (150ms)
- Personality: Smooth and refined — no bouncing, no dramatic effects. Feels considered.

SECTION-SPECIFIC:
- Hero: Full viewport height. Name in oversized serif (clamp between 64px–120px). Tagline in smaller sans-serif below. Subtle scroll indicator at bottom. Name and tagline left-aligned for editorial feel. Small accent line or dot in gold near the name.
- About: Two-column layout on desktop (text left, visual accent or decorative element right). NOT a centered paragraph block. Include placeholder text about background, skills, and experience. Use a thin horizontal rule as section divider.
- Contact: Clean, minimal. Email as a large styled link (not a form). Row of social media icons (GitHub, LinkedIn, Twitter/X, Dribbble) with hover states. Asymmetric layout — email large on left, icons stacked or inline on right.
- Header: Minimal — name/wordmark left, nav links right (About, Contact). Transparent over hero, solid on scroll.
- Footer: Single line, minimal — copyright only. Matches dark aesthetic.

DIFFERENTIATION:
Oversized serif name in the hero that breaks the typical "centered hero with subtitle" pattern. Left-aligned editorial layout creates a magazine/editorial feel that stands out from typical portfolio templates.

CONSISTENCY:
Dark, warm aesthetic maintained throughout all sections. Gold accent used consistently for interactive states and decorative touches. Animation timing consistent — all entrances use easeOut, all hovers 150ms.
