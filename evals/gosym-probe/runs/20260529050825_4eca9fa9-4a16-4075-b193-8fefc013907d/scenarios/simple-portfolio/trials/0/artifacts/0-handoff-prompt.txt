Build homepage design preview with this direction:

PROJECT DETAILS:
- Name & tagline: Jordan Lee — Full-stack developer & creator
- Field: Software Engineer
- Visual vibe: Dark & sleek (dark background, glowing accents)

DESIGN DIRECTION:
A dark, high-contrast portfolio that feels premium and technical without being cold. Deep near-black background with a single electric accent (cyan or violet) used as a glow and highlight. The page should feel like a late-night coding session — focused, atmospheric, alive.

LAYOUT TYPE: Standard
Marketing/portfolio site with full navigation structure.

VISUAL DIRECTION:
- Color: Deep charcoal/near-black base (#0d0d0f range), with ONE electric accent — cyan (#00d4ff) or soft violet (#a78bfa). Use accent for glows, underlines, and hover states only. Muted gray for secondary text.
- Typography: Monospace or geometric sans for name/headings (try "Space Grotesk" or "JetBrains Mono" for the name, clean sans for body). Bold weight contrasts. Generous letter-spacing on labels.
- Layout: Asymmetric hero with name large-left and a subtle geometric/grid graphic right. Sections separated by generous dark space, not dividers.

VISUAL ELEMENTS:
- Primary: Geometric/grid graphics — subtle dot grid or line grid pattern as background texture, very low opacity
- Style: Technical, precise — thin lines, node dots, grid overlays suggesting code/data
- Application: Hero background (very subtle), section accent elements, decorative corner marks
- Logo: Use media-logo skill to generate a minimal monogram logo ("JL") in the accent color for the header

MOTION DESIGN:
- Level: Subtle to dynamic
- Effects:
  - Hero name: staggered character or word fade-in (500ms, ease-out)
  - Tagline: fade-in with slight upward drift after name animates (300ms delay)
  - Sections: fade-in on scroll with slight upward translate (whileInView, once: true)
  - Accent glow elements: gentle pulse animation (3-4s, repeat infinite, subtle opacity shift)
  - Nav links: underline-draw on hover (200ms)
  - Contact icons: scale + glow on hover
- Personality: Smooth and precise — like a well-engineered UI, not flashy

SECTION-SPECIFIC:

Hero:
- Full viewport height
- Large typographic name "Jordan Lee" — oversized, breaking the grid slightly
- Tagline below: "Full-stack developer & creator" in muted accent color or gray
- Subtle dot-grid or circuit-line background pattern (very low opacity, ~5-8%)
- CTA button: "View My Work" with accent border + glow on hover
- Animated entrance: staggered word-by-word or line-by-line reveal

About:
- Two-column layout: left side has a short bio paragraph, right side has 3-4 stat/highlight cards (e.g., "5+ years experience", "20+ projects shipped", "Open source contributor")
- Cards use subtle border with accent glow on hover
- NOT a list of bullet points — flowing paragraph prose

Contact:
- Clean, minimal — NOT a centered-band CTA
- Asymmetric layout: large "Let's build something." heading left, contact details right
- Email link with accent color + underline
- Social icons: GitHub, LinkedIn, Twitter/X — row of icons with scale + glow hover effect
- Icons should be from lucide-react or heroicons

Footer:
- Minimal — just copyright and nav links
- Maintain dark aesthetic, no jarring color change

DIFFERENTIATION:
Oversized hero name that slightly overflows or breaks the grid boundary. The name should feel monumental — like it owns the page. Pair with a subtle glowing accent line or underline beneath it.

CONSISTENCY:
Dark atmosphere maintained throughout every section. Accent color used sparingly but consistently. Footer as intentional as hero — no quality drop-off.
