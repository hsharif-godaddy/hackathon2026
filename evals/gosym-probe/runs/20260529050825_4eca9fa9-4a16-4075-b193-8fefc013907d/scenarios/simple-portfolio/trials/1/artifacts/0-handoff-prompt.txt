Build a personal portfolio homepage with this design direction:

PROJECT DETAILS:
- Type: Personal portfolio website
- Sections: Hero, About, Contact
- Design: Clean, modern, well-spaced

DESIGN DIRECTION:
Refined and minimal with confident typographic hierarchy. Should feel like a thoughtful designer/developer's personal site — not a generic template. Generous whitespace, editorial layout, and one distinctive typographic moment create memorability without noise.

LAYOUT TYPE: Standard
Marketing/portfolio site with full navigation structure.

VISUAL DIRECTION:
- Color: Near-black base (#0f0f0f or deep charcoal) with a warm off-white for text, and ONE crisp accent — a muted warm gold or sage green. Not blue, not purple.
- Typography: Elegant contrast — a refined serif display font (Playfair Display or DM Serif Display) for headings, clean geometric sans (DM Sans or Plus Jakarta Sans) for body. Dramatic size contrast between heading and body.
- Layout: DO NOT use centered-text-only hero. Use an asymmetric composition with name large on the left, tagline below with a subtle decorative rule. About section uses a two-column layout (text left, visual accent right). Contact section is minimal and confident — not a form, just links.

VISUAL ELEMENTS:
- Primary: Typographic — let the type do the heavy lifting
- Style: Subtle geometric line accents (thin horizontal rules, small decorative marks) in the accent color
- Application: Thin rule under hero name, section dividers as design elements, accent color on hover states
- Logo: Use the media-logo skill to generate a minimal monogram or wordmark logo for the header

MOTION DESIGN:
- Level: Subtle
- Effects:
  - Hero name fades and slides up on load (500ms, easeOut)
  - Tagline follows with 150ms delay
  - About and contact sections fade in on scroll (viewport: once)
  - Hover states on links: smooth underline draw animation (200ms)
  - Social icons: gentle scale on hover (1.1x, 150ms)
- Personality: Calm and refined — nothing bouncy, nothing fast

SECTION-SPECIFIC:
- Hero: Full viewport height. Name in large serif (80-100px desktop), tagline in sans below with a thin accent-colored rule separating them. Navigation links fade in from top. Subtle scroll indicator at bottom.
- About: Two-column layout — left has the text content (background, skills, personality), right has a large decorative initial letter or abstract geometric shape in the accent color. NOT a photo placeholder.
- Contact: Minimal section — email as a large styled link, social icons (GitHub, LinkedIn, Twitter/X) as clean icon buttons below. No form. Asymmetric layout, not centered-on-band.
- Header: Minimal — monogram/logo left, sparse nav right (About, Work, Contact). Transparent over hero, solid on scroll.
- Footer: Single line — copyright and a "back to top" link. Matches the refined tone.

DIFFERENTIATION:
Oversized serif name in the hero that breaks the grid slightly — extends close to the viewport edge. This creates an editorial, magazine-like first impression rather than a typical portfolio template.

CONSISTENCY:
Dark, refined aesthetic maintained throughout all sections. Accent color used sparingly as punctuation. Footer as intentional as the hero — no quality drop-off.
