Build a personal portfolio homepage with this design direction:

PROJECT DETAILS:
- Type: Personal portfolio
- Sections: Hero, About, Contact
- Design: Clean, modern, good spacing

DESIGN DIRECTION:
Editorial and confident — a portfolio that feels like a designer or developer who has taste. Strong typographic hierarchy with generous whitespace. Not a generic template — the layout should feel intentional and slightly unexpected.

LAYOUT TYPE: Standard
Multi-page portfolio site with full header navigation and footer.

VISUAL DIRECTION:
- Color: Near-black base (#0F0F0F or similar) with a warm off-white for text, and ONE warm accent — a muted amber or soft gold. Not blue, not purple. Sophisticated and distinctive.
- Typography: Large, confident display serif for the hero name (something like Playfair Display or DM Serif Display). Clean geometric sans-serif (like DM Sans or Plus Jakarta Sans) for body and nav. Dramatic size contrast between heading and body.
- Layout: DO NOT use centered hero with text only. Use an asymmetric two-column hero — name/tagline left, a subtle decorative element or abstract graphic right. Generous section padding.

VISUAL ELEMENTS:
- Primary: Geometric/abstract graphics — subtle grid lines, dot patterns, or thin geometric shapes as decorative accents
- Style: Minimal, precise — think editorial design, not tech startup
- Application: Hero right column as abstract graphic, section dividers as thin lines, subtle dot grid texture in background
- Logo: Use the media-logo skill to generate a minimal wordmark logo for the header

MOTION DESIGN:
- Level: Subtle
- Effects:
  - Hero name fades and slides up on load (400ms, ease-out)
  - Tagline staggered after name (200ms delay)
  - About and contact sections fade in on scroll (viewport once: true)
  - Nav links have elegant underline-draw hover effect
  - Social icons have subtle scale + opacity hover (150ms)
- Personality: Refined and deliberate — nothing bouncy, nothing fast

SECTION-SPECIFIC:
- Hero: Asymmetric layout, name in large display serif (5xl–7xl), tagline in muted foreground color below. Abstract geometric graphic on the right (thin lines, circles, or grid). Animated entrance.
- About: Two-column on desktop — short punchy bio left, skills/highlights right. Use a thin horizontal rule above the section heading. Fade in on scroll.
- Contact: NOT a centered colored band. Use a full-width section with large typographic "Let's Talk" or "Get in Touch" heading, email as a large styled link (not a button), and social icons (GitHub, LinkedIn, Twitter/X) as minimal icon links with hover effects. Keep it elegant.
- Header: Minimal — logo/name left, nav links right. Clean and unobtrusive.
- Footer: Single line, minimal — copyright and a small "back to top" link. Matches the dark aesthetic.

DIFFERENTIATION:
Oversized display serif name in the hero that breaks the grid — set it large enough that it feels like a design statement, not just a heading. The contrast between the massive name and the small, precise body text creates immediate visual impact.

CONSISTENCY:
Dark, editorial aesthetic throughout. The contact section should feel as considered as the hero — large type, lots of breathing room. No section should feel like an afterthought.

Phase 2 — Structure (run these in parallel, after Phase 1):
