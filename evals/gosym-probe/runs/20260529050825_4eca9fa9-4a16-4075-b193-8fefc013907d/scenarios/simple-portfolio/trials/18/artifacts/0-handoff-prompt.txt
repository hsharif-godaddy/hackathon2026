Build a personal portfolio homepage with this design direction:

PROJECT DETAILS:
- Type: Personal portfolio website
- Sections: Hero, About, Contact
- Design: Clean, modern, well-spaced

DESIGN DIRECTION:
Editorial and confident with generous whitespace. Monochrome base with a single warm accent that punctuates key elements. Should feel like a thoughtful designer/developer's portfolio — not a generic template. Typography does the heavy lifting.

LAYOUT TYPE: Standard
Marketing/portfolio site with full navigation structure.

VISUAL DIRECTION:
- Color: Near-black base (#0f0f0f or similar) with warm off-white text, punctuated by a single warm accent (amber or coral). NOT the typical blue/purple combo.
- Typography: Bold, oversized display type for the hero name — dramatic size contrast between headline and body. Mix a strong serif or editorial sans for headings with a clean readable sans for body.
- Layout: Asymmetric hero with name breaking the grid at large scale. About section uses a two-column layout (not centered text block). Contact section is minimal and elegant — NOT a centered-on-band CTA.

VISUAL ELEMENTS:
- Primary: Typography-driven — the name and words ARE the visual
- Style: Minimal decorative elements; subtle geometric line accents if needed
- Application: Thin horizontal rules, generous section padding, intentional whitespace
- Logo: Use the media-logo skill to generate a minimal wordmark/monogram logo for the header

MOTION DESIGN:
- Level: Subtle
- Effects: Staggered fade-up entrance for hero text (name first, then tagline, then CTA), fade-in on scroll for About and Contact sections, smooth underline-draw hover on nav links and social icons
- Personality: Refined and deliberate — nothing bouncy, everything smooth (ease-out, 300-400ms)

SECTION-SPECIFIC:
- Hero: Full-viewport height. Name displayed at very large scale (clamp-based fluid type, e.g. 6rem–12rem). Tagline below in smaller weight. Subtle scroll indicator at bottom. Staggered entrance animation.
- About: Two-column layout — short punchy label/heading on left, paragraph text on right. NOT a centered text block. Fade-in on scroll.
- Contact: Clean, left-aligned layout. Email as a styled link (not a button). Social icons (GitHub, LinkedIn, Twitter/X) as minimal icon links with hover underline or color shift. No colored band background.
- Header: Minimal — logo/monogram left, sparse nav right (About, Contact). Transparent over hero, solid on scroll.
- Footer: Single line — copyright and a subtle "back to top" link. Matches the refined tone.

DIFFERENTIATION:
Oversized hero name that breaks the grid — fluid typography scaling from ~6rem to ~12rem. This is the memorable element. The warm accent color appears only on hover states and the tagline, creating intentional restraint.

CONSISTENCY:
Maintain the editorial restraint throughout. The contact section should feel as considered as the hero. No energy drop toward the bottom of the page. Hover animations consistent (200ms, ease-out) across all interactive elements.

Phase 2 — Structure (run in parallel, after Phase 1):
