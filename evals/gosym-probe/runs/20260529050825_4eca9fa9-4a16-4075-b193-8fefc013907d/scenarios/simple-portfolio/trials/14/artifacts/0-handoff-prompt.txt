DESIGN DIRECTION:
Bold, editorial portfolio that feels like a designer made it — not a template. Strong typographic hierarchy with dramatic size contrasts, confident use of whitespace, and one unexpected accent color that punctuates the monochrome base. LAYOUT TYPE: Standard
Marketing/portfolio site with full navigation header and footer.

VISUAL DIRECTION:
- Color: Near-black base (#0F0F0F or similar) with a single vivid accent — consider electric violet (#7C3AED) or warm coral (#F97316) as the punctuation color. Off-white text. Muted gray for secondary text.
- Typography: Dramatic display serif or high-contrast sans for headings (try Playfair Display or Fraunces for hero, DM Sans or Plus Jakarta Sans for body). Oversized hero name that breaks the grid. Mix weights boldly.
- Layout: Asymmetric compositions throughout. NO centered-text-on-colored-band CTAs. NO uniform icon grids.

VISUAL ELEMENTS:
- Primary: Abstract geometric shapes — thin lines, circles, dot grids — in the accent color as subtle decorative elements
- Style: Minimal, precise, editorial — think design magazine aesthetic
- Application: Hero background accents, section dividers, floating decorative marks
- Logo: Generate a minimal wordmark logo using the media-logo skill — "SM" monogram or "Sarah Mitchell" wordmark in a clean, bold style matching the dark aesthetic

MOTION DESIGN:
- Level: Dynamic
- Effects:
  - Hero name: staggered letter/word entrance (slide up + fade, 600ms, staggered 80ms per word)

  - Hover on social icons: scale(1.15) + accent color shift (150ms)
  - Decorative shapes: slow ambient float (6-10s, subtle y-axis movement)
- Personality: Confident and creative — smooth, deliberate, never bouncy
