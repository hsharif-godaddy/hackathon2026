Build a personal portfolio homepage with this design direction:

PROJECT DETAILS:
- Type: Personal portfolio website
- Sections: Hero, About, Contact
- Design: Clean, modern, well-spaced

DESIGN DIRECTION:
Editorial and confident — a portfolio that feels like a designer or developer who has taste. Strong typographic hierarchy with generous whitespace. Not a generic template — it should feel personal and intentional.

LAYOUT TYPE: Standard
Multi-page portfolio site with full navigation structure.

VISUAL DIRECTION:
- Color: Near-black background (#0f0f0f or similar deep charcoal) with crisp white text and ONE warm accent (amber/gold or coral) used sparingly for highlights and hover states. Creates premium, editorial feel.
- Typography: Tall, expressive serif or display font for the hero name (something like Playfair Display or DM Serif Display), paired with a clean geometric sans for body copy (DM Sans or Plus Jakarta Sans). Bold size contrast — hero name should be very large.
- Layout: Full-bleed sections with generous vertical padding. Asymmetric hero with name large on left, tagline smaller below. About section uses a two-column layout (bio text left, a subtle decorative element or skills list right). Contact section is minimal and elegant.

VISUAL ELEMENTS:
- Primary: Typographic — let the type do the work
- Style: Minimal geometric accents (thin lines, subtle grid dots) in the hero background
- Application: Subtle dot-grid or line pattern in hero background at low opacity; accent color used on hover states and one or two key highlights
- Logo: Use the media-logo skill to generate a simple wordmark/monogram logo for the header

MOTION DESIGN:
- Level: Subtle
- Effects:
  - Hero name and tagline fade up on load (staggered, 400ms each)
  - Section content fades in on scroll (viewport: once: true, 350ms ease-out)
  - Navigation links have elegant underline-draw hover effect
  - Social media icons scale slightly on hover (1.1x, 150ms)
  - Smooth scroll between sections
- Personality: Refined and deliberate — nothing bouncy, everything smooth

SECTION-SPECIFIC:
- Hero: Large name (display font, 80-100px desktop), tagline below in lighter weight, a subtle CTA "View my work" or "Get in touch" link with accent color. Dot-grid background pattern at low opacity. Staggered fade-up entrance animation.
- About: Two-column layout — left has 2-3 paragraph bio placeholder, right has a short skills/interests list or a decorative typographic element. Fade in on scroll.
- Contact: Clean, minimal. Email address as a styled link (large, accent color on hover). Row of social media icons (GitHub, LinkedIn, Twitter/X, Dribbble) with hover scale effect. Short headline like "Let's work together."
- Header: Minimal — logo/name left, nav links right (About, Work, Contact). Transparent over hero, solid on scroll.
- Footer: Single line — copyright and name. Matches dark aesthetic.

DIFFERENTIATION:
Oversized hero typography that breaks the expected scale — the name should feel monumental. Pair with the dot-grid texture for depth without distraction.

CONSISTENCY:
Dark, editorial aesthetic maintained throughout all sections. Accent color used consistently for interactive elements. Footer as intentional as hero.
