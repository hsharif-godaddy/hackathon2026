Build a personal portfolio homepage with this design direction:

PROJECT DETAILS:
- Type: Personal portfolio website
- Sections: Hero, About, Contact
- Design: Clean, modern, well-spaced

DESIGN DIRECTION:
Editorial and refined — a portfolio that feels like a thoughtfully designed magazine spread, not a generic developer template. Strong typographic hierarchy, generous whitespace, and a warm-neutral palette that lets the person's personality shine through.

LAYOUT TYPE: Standard
Full header with navigation and footer.

VISUAL DIRECTION:
- Color: Warm off-white background (#F9F7F4 feel) with deep charcoal text and a single warm accent (terracotta or dusty amber — NOT blue or purple). Subtle warm tones throughout.
- Typography: Pair a refined serif display font (like Playfair Display or DM Serif Display) for headings with a clean geometric sans (like DM Sans or Plus Jakarta Sans) for body. Bold size contrast — hero name should be very large.
- Layout: DO NOT use centered-everything layout. Use asymmetric compositions — name left-aligned with large scale, about section with offset text/visual columns, contact section integrated elegantly.

VISUAL ELEMENTS:
- Primary: Minimal geometric accents — thin lines, subtle dot grids, or small geometric shapes as decorative elements
- Style: Clean and editorial, not flashy
- Application: Subtle decorative lines near section headings, a soft background texture or shape in the hero
- Logo: Use the media-logo skill to generate a simple monogram or wordmark logo for the header

MOTION DESIGN:
- Level: Subtle
- Effects:
  - Fade-in + slide-up on scroll for each section (350ms, ease-out)
  - Staggered entrance for hero text (name first, then tagline)
  - Gentle hover underline draw on nav links
  - Hover lift on social media icons (translate-y + opacity)
- Personality: Smooth and refined — nothing bouncy, everything intentional

SECTION-SPECIFIC:
- Hero: Large left-aligned name (display serif, very large — 5xl to 7xl), tagline below in sans-serif, a subtle geometric accent or soft shape in the background. Staggered entrance animation.
- About: Two-column asymmetric layout — text on one side, a visual element (abstract shape, decorative block, or placeholder for photo) on the other. NOT a centered paragraph block.
- Contact: Elegant, NOT a centered-band CTA. Email as a large styled link, social icons (GitHub, LinkedIn, Twitter/X) with hover effects. Could use a split layout or offset card.
- Header: Minimal — monogram/logo left, nav links right with hover underline animations
- Footer: Simple, warm, matches overall tone — not an afterthought

DIFFERENTIATION:
The hero name should be typographically oversized and bold — breaking the grid slightly to create immediate visual impact. This is the one element that makes it feel like a real designer's portfolio, not a template.

CONSISTENCY:
Maintain the warm editorial tone throughout — footer should feel as considered as the hero. Keep animation timing consistent (subtle, 300-400ms range).
