# Start command for services

When asked about starting services, start this list in parallel. You HAVE TO use the right port :

## Agent

**EXECUTE** `cd agents && pnpm run dev`
**PORT** 4000

## App

**EXECUTE** `cd app && pnpm run dev`
**PORT** 3000

## Template

**EXECUTE** `cd app-templates/v8 && pnpm run dev`
**PORT** 5173
