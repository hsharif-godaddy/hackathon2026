# GoDaddy UX Content Design Playbook

The UX Content Design Team creates continuity of experience and ease of use through language. This playbook is a how-to for writing in-product experiences, based on the [GoDaddy Brand Identity Guidelines](https://www.assets.godaddy/guidelines/guide/3a3fdf70-f3ca-486e-8545-d968800bb009) with variations tailored to in-product writing.

## When to Use

Use this skill when you need to:

- **Write UI copy** for any GoDaddy product screen (headlines, body copy, labels, tooltips)
- **Craft error messages, alerts, or loading states** with proper tone and format
- **Format buttons and CTAs** with correct casing and word count
- **Choose the right voice and tone** for a customer moment (serious vs lighthearted, urgent vs low-pressure)
- **Apply style rules** for punctuation, capitalization, word choice, and formatting
- **Write for mobile** with mobile-specific constraints and patterns
- **Ensure content consistency** across GoDaddy product experiences
- **Review or polish** existing product copy against GoDaddy standards

**For GoDaddy brand identity** (logo, brand colors, photography, illustrations, campaigns), use the `brand-guidelines` skill. Both skills share the same Doubt Slayer voice — this skill provides the practical writing rules for product surfaces.

### Capitalization Quick Reference

| Element | Format | Period | Example |
|---------|--------|--------|---------|
| Headlines | Sentence case | No (single sentence) | "Get more followers with social ads" |
| Section titles | Title case | No | "More Ways to Sell" |
| Buttons (standard) | Title case | No | "Start for Free" |
| Buttons (long) | Sentence case | No | "Continue with your current plan" |
| Tertiary CTAs | Sentence case | No | "Explore our plan types" |
| Body copy | Sentence case | Yes | "We'll help you set up your site." |
| Tooltips | Sentence case | Yes | "This helps protect your account." |
| Eyebrows/subheads | Sentence case | Yes | "You're one step closer to launching." |
| Labels | Sentence case | No | "Email address" |
| Tags | ALL CAPS | No | "NEW" |

### Non-Negotiable Rules

1. **Use serial commas** — "email, a blog, and a domain" (differs from Brand)
2. **Use active voice** — "You're deleting images" not "Images will be deleted"
3. **Use contractions** — "We'll email you" not "We will email you"
4. **Use numerals** — "4 out of 10" not "Four out of 10"
5. **No emojis** in UI content
6. **No ALL CAPS** for emphasis
7. **Use "sign in/out"** not "log in/out"
8. **Use sentence case** for most UI text
9. **Never say "click here"** — link the destination or action
10. **Bold** domain names, product areas, and statuses — never use italics

### Common Word Choices

| Use This | Not This |
|----------|----------|
| create (customers) | build (customers) |
| sign in / sign out | log in / log out |
| see | view |
| email, ecommerce, ebook | e-mail, e-commerce, e-book |
| canceled | cancelled |
| traveled | travelled |
| allowlist / blocklist | whitelist / blacklist |
| turn on / turn off | enable / disable |
| set up (verb) | setup (verb) |
| setup (noun) | set up (noun) |
