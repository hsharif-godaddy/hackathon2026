## 1. Background Builds: Submit, Close the Tab, Come Back Later

### What changed

The disconnect timeout is gone. After you submit your first prompt and finish the initial Q&A with the agent, your build **keeps running in the background** even if you close the browser tab.

The build only pauses if the agent needs your input again.

### What this means for you

**Before:** You had to keep the tab open and watch the build finish. Step away and you risked losing progress.

**Now:** Write your prompt. Submit. Answer the agent's opening questions. Close the tab and go do something else. Come back to continued progress on your build.

This is especially helpful for first-time builds, which take longer while the agent sets up your site structure, copy, and layout.

### How to use it

1. Start a new project and describe what you want to build.
2. Answer any questions the agent asks at the start.
3. Once the agent is working on the build, you can close the tab or switch apps.
4. Return to [Airo AI Builder](https://airo-builder.godaddy.com?referralId=DamWZ-ryeCH7) when you are ready. Your project will be waiting.

If the agent needs a decision from you, the build pauses until you respond.

New to prompting? See [10 Prompts You Can Copy to Build Real Apps Today](/blog/10-prompts-build-real-apps-today) or watch [How to Maximize Your AI Credits](https://youtu.be/1dkMmsiAOKc) on YouTube.

## 2. Attach a File to Your First Prompt

### What changed

You can now attach a supporting file as part of your **first prompt** on the [Airo AI Builder home page](https://airo-builder.godaddy.com/). Drag and drop a file onto the prompt area or use the file picker. Once attached, the builder fills in a starter prompt for you and enables the **Generate** button so you can kick off your build right away.

### What this means for you

**Before:** You had to describe everything from scratch in the prompt box, even if you already had a doc, mockup, or old site file ready to go.

**Now:** Bring what you have into the first step. Useful if you have:

- A **.md** or **.txt** file with business details, copy, or a brief
- An **.html** file from an existing site you want to rebuild or improve
- **Images** (PNG, JPG, SVG, and more) for logos, product shots, or reference visuals
- A **.zip** with assets bundled together

The agent reads your file as context for the build instead of making you retype it all.

### Supported file types

`.md` · `.txt` · `.xml` · `.html` · `.htm` · `.zip` · `.png` · `.jpg` · `.jpeg` · `.gif` · `.svg` · `.webp`

### How to use it

1. Go to the [Airo AI Builder home page](https://airo-builder.godaddy.com/).
2. Drag a file into the prompt area, or click to open the file picker.
3. Review the starter prompt the builder generates from your file.
4. Edit the prompt if you want, then click **Generate**.

Have an old site or brief ready? Pair this with [10 Prompts You Can Copy to Build Real Apps Today](/blog/10-prompts-build-real-apps-today) for stronger first builds.

## 3. Optimize Your Site for Search (SEO + AEO)

### What changed

You can now prompt **"Optimize my site for SEO"** and the agent walks through your pages with you. It helps update page titles, meta descriptions, and on-page structure so your site reads clearly to search engines and AI systems.

### What this means for you

**Before:** You published and hoped Google (or an AI assistant) would figure out what you do.

**Now:** You can actively tune your site for discoverability without hiring an SEO consultant or installing plugins.

This matters in two places:

- **SEO** is how customers find you when they search on Google. Think page titles, descriptions, and content that matches what people type.
- **AEO (Answer Engine Optimization)** is how you may show up when someone asks an AI assistant a question like *"Who does web design for small bakeries near me?"* instead of searching keywords.

| | SEO | AEO |
|---|-----|-----|
| **Where you show up** | Google and Bing search results | ChatGPT, Gemini, Perplexity, AI Overviews |
| **What helps** | Page titles, descriptions, sitemap | Clear content, business details, structured pages |
| **What June adds** | Prompt: "Optimize my site for SEO" | Same prompt; pages tuned for machines and AI systems to read |

Most small business sites miss both. Yours does not have to.

### How to use it

1. Open your project in [Airo AI Builder](https://airo-builder.godaddy.com?referralId=DamWZ-ryeCH7).
2. Type **"Optimize my site for SEO"** in the prompt bar.
3. Review what the agent suggests. Accept changes page by page.
4. Publish (or republish) when you are happy.

If you built with us in [May](/blog/airo-ai-builder-product-update-may-2026), you already have server-rendered pages and automatic sitemap files. This prompt builds on that foundation. You are not starting from zero.

## 4. See How Your Site Is Performing (Analytics)

### What changed

Analytics now live inside [Airo AI Builder](https://airo-builder.godaddy.com?referralId=DamWZ-ryeCH7). For published sites, you can see **page views**, **visitors**, and **clicks** without opening Google Analytics or another dashboard.

### What this means for you

**Before:** You published and had no simple way to know if anyone was visiting.

**Now:** You get a quick read on whether your site is getting traction. That helps you decide what to improve next: a headline, a new page, or an SEO pass.

You do not need to be a data analyst. Start with three questions:

- Are people landing on my site?
- Which pages get the most views?
- Are visitors clicking where I want them to?

When you see a number move, you can prompt your next change in the same session.

### How to use it

1. Publish your site (or open an already published project).
2. Open the analytics view in the builder.
3. Check page views, visitors, and clicks over time.
4. Use what you learn to prompt updates: new copy, a new section, or an SEO optimization pass.

## 5. Automatic Email Notifications for App Transfers

### What changed

App transfer emails are now live. When you start or accept an app transfer, [Airo AI Builder](https://airo-builder.godaddy.com?referralId=DamWZ-ryeCH7) sends **automatic email updates** to your inbox at each step of the process.

### What this means for you

**Before:** You had to stay in the product and manually check whether a transfer went through, expired, or was waiting on the other person.

**Now:** Your email keeps you in the loop automatically.

**If you are sending an app:**

- You get a confirmation when the transfer starts, including the transfer code to share.
- You get a heads-up if the code is about to expire.
- You get a confirmation when the recipient accepts, or a notice if the transfer times out.

**If you are receiving an app:**

- You get an invitation email with instructions to accept (or create an account and accept).
- You get a confirmation when the app lands in your account, with next steps if anything needs reconnecting.

These are service emails tied to actions you take. They are not marketing messages.

### How to use it

1. Start or accept a transfer as you normally would inside [Airo AI Builder](https://airo-builder.godaddy.com?referralId=DamWZ-ryeCH7).
2. Check the email address on your GoDaddy account for updates.
3. Use the links in each email to jump back into the transfer flow if you need to accept, share a code, or check status.

No extra setup required. If a transfer is in progress, your inbox should reflect it.

Step-by-step handoff guide: [How to Transfer Apps Between Accounts](/blog/how-to-transfer-apps-between-accounts). Video: [App transfer walkthrough on YouTube](https://youtu.be/s_u-NBkg7SM).

## 6. Edit Images Without Leaving the Builder

### What changed

Image editing tools are now built into your site preview. You can adjust **brightness**, **contrast**, **hue**, **saturation**, **blur**, and **filters** from the same place you build.

### What this means for you

**Before:** You downloaded an image, edited it in another app, re-uploaded it, and lost time every time something looked off.

**Now:** You fix it in place. Your site looks more polished without breaking your flow.

This is especially useful if you are iterating on a homepage hero, product photos, or team headshots and want small tweaks without a full rebuild.

### How to use it

1. Open your site preview.
2. Select the image you want to change.
3. Open the media editor.
4. Adjust settings until it looks right.
5. Save and keep building.

## 7. Share Feedback and Get a Chance to Be Featured

### What changed

When you rate your experience in the **Share feedback** flow, you can now opt in to let GoDaddy publicly share your feedback along with your **business name and website**.

### What this means for you

**Before:** Your feedback stayed internal. There was no easy way to raise your hand if you loved what you built and wanted others to see it.

**Now:** If you are happy with your project, you can choose to share your story. That helps other builders see real examples of what is possible with [Airo AI Builder](https://airo-builder.godaddy.com?referralId=DamWZ-ryeCH7).

Opting in gives you a chance to be featured on **GoDaddy's blog, social channels, or website** as a customer story or testimonial. GoDaddy selects stories at its discretion; not every opt-in is featured.

You stay in control. Public sharing only happens if you check the consent box. You can also opt in to be contacted about your feedback without agreeing to public sharing.

### How to use it

1. Open the feedback prompt inside your project (usually after a positive experience or from the feedback entry point in the product).
2. Rate how likely you are to recommend Airo AI Builder.
3. Optionally pick a category (Editor & design, AI assistant, Publishing & domains, and more) and add a comment.
4. Check **"GoDaddy may publicly share my feedback and business name/website"** if you want to be considered for a feature.
5. Click **Send feedback**.

## Frequently Asked Questions

### What is new in Airo AI Builder for June 2026?

June adds background builds, file attach on the first prompt, SEO and AEO optimization, in-app analytics, built-in image editing, app transfer email notifications, and optional public-sharing consent when you submit feedback. ### Can I close the browser while my site is building?

Yes. After you submit your first prompt and answer the agent's initial questions, the build continues in the background even if you close the tab. The disconnect timeout is removed, so you are not tied to an open browser window. The build only pauses if the agent needs your input.

GoDaddy selects stories at its discretion; public sharing only happens with your consent.

### Can I attach a file when I start a new build?

Yes. On the [Airo AI Builder home page](https://airo-builder.godaddy.com/), drag and drop a file into the prompt area or use the file picker. Supported types include markdown, text, HTML, XML, ZIP, and common image formats. The builder uses your file to populate a starter prompt and enables Generate so you can start building immediately.

### Will I get email notifications when I transfer an app?

Yes. When you start or accept an app transfer, you receive automatic emails at each step: confirmation when a transfer begins, invitation or acceptance prompts for the recipient, completion notices for both parties, and alerts if a transfer code is expiring or has expired.

### What is AEO and why should I care?

AEO (Answer Engine Optimization) helps AI assistants like ChatGPT and Gemini understand and recommend your business when people ask questions instead of searching Google. Clear page content, business details, and structured pages can help AI systems cite your site in those answers.

Open your project and type **"Optimize my site for SEO"** in the prompt bar. The agent will suggest updates to titles, descriptions, and page content. Review each change before publishing.

No. Those June features are available on the free plan and paid plans. App transfer emails apply when you use the app transfer flow.

Your site already benefits from May's technical SEO foundation (server rendering, sitemap, robots.txt). June adds an optional prompt so you can actively tune titles and descriptions whenever you want.
