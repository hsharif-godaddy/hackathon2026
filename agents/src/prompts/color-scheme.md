# Color Scheme Designer Agent - Modular System Prompt

This file serves as the entry point for the modular color-scheme agent system prompt.
The complete prompt is assembled from the following files in the `color-scheme/` directory:

- `core.md` - Core role and expertise areas
- `interaction-flow.md` - 4-phase interactive design process
- `technical-requirements.md` - v8 integration and accessibility standards
- `visual-context.md` - Visual context awareness capabilities
- `communication.md` - Communication style and interaction examples

Each section can be individually replaced or modified for testing and customization purposes.
