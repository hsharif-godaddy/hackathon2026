# App Template (v8)

Vite + React 19 with TypeScript, shadcn UI, Tailwind CSS, and vite-plugin-api.

## Tech Stack

- **Frontend**: Vite + React 19 + TypeScript
- **UI**: shadcn UI components (40+ pre-installed)
- **Styling**: Tailwind CSS with CSS variables
- **Animation**: Motion for animations and transitions
- **API**: vite-plugin-api for `/api/*` routes
- **Testing**: Vitest
- **State**: React hooks, Context API, Zustand
- **SEO**: Native React 19 document metadata (no external libraries needed)

## Directory Structure

## Layout System

### Available Layouts

- **RootLayout** (`src/layouts/RootLayout.tsx`): Multi-page websites with shared header/footer
- **Dashboard** (`src/layouts/Dashboard.tsx`): Admin panels, SaaS apps

### Critical Rules

1. **ALWAYS read `App.tsx` first** before modifying routes or layouts
2. **Read layout `.md` documentation** before implementation
3. **For websites**: Configure header/footer once in `App.tsx`, pages render content only
4. **For dashboards**: Use Dashboard layout directly
5. **NEVER** duplicate header/footer across pages
6. **NEVER** create custom `min-h-screen` containers

## Header and Footer

### File Locations

- `src/layouts/parts/Header.tsx` - Main navigation header
- `src/layouts/parts/Footer.tsx` - Site footer

### Available Styles

**Headers**: Simple (blog/portfolio), Professional (corporate), Creative (artistic), E-commerce (with search/cart)

**Footers**: Minimal (copyright only), Multi-column (links grid), Social (social icons focused)

### When to Remove Header/Footer

For dashboards, games, and single-page apps, edit `src/layouts/RootLayout.tsx`:

```tsx
export default function RootLayout({ children }: RootLayoutProps) {
  return <Website>{children}</Website>;
}
```

### Customization Tips

- Edit TSX files directly (no config objects)
- Match style to website type
- Update navigation to match actual pages
- Keep mobile menu functionality

## Color System

All colors use CSS variables in `src/styles/globals.css`. Always use variables, never hard-code colors.

### Core Variables

**Base**: `--background`, `--foreground`, `--card`, `--card-foreground`, `--popover`, `--popover-foreground`

**Brand**: `--primary`, `--primary-foreground`, `--secondary`, `--secondary-foreground`, `--accent`, `--accent-foreground`

**UI**: `--muted`, `--muted-foreground`, `--destructive`, `--destructive-foreground`, `--border`, `--input`, `--ring`

**Dashboard**: `--sidebar`, `--sidebar-foreground`, `--sidebar-primary`, `--sidebar-accent`, `--sidebar-border`

### Usage Examples

```tsx
// Backgrounds
<div className="bg-background">...</div>
<div className="bg-primary">...</div>
<div className="bg-card">...</div>

// Text
<p className="text-foreground">...</p>
<p className="text-muted-foreground">...</p>

// Borders
<div className="border border-border">...</div>

// Inline styles (with hsl wrapper)
<div style={{ background: `hsl(var(--primary))` }}>...</div>
```

### Image Overlays

For overlays on images, use neutral gray gradients (not brand colors):

```tsx
<div className="absolute inset-0 bg-gradient-to-b from-gray-900/60 to-gray-900/80" />
```

## Animation (Motion)

Motion is pre-installed. Import with `import { motion } from "motion/react"` and use `motion.*` components.

### Common Patterns

- **Entrance**: `initial` + `animate` for mount animations
- **Scroll**: `whileInView` with `viewport={{ once: true }}` for scroll-triggered
- **Hover**: `whileHover` for interactive effects
- **Stagger**: `variants` with `staggerChildren` for sequential animations

### Timing Guidelines

- Hovers/interactions: 150-200ms
- Entrance animations: 300-500ms
- Ambient/floating: 3-8s with `repeat: Infinity`

## SEO & Document Head (React 19 Native)

React 19 supports document metadata management natively - no external libraries needed! You can set `<title>`, `<meta>`, and other tags directly in components.

### Basic Usage

```tsx
export default function AboutPage() {
  return (
    <>
      <title>About Us - My Company</title>
      <meta name="description" content="Learn more about our company and team." />
      <div>{/* Page content */}</div>
    </>
  );
}
```

### Best Practices

- Set unique `<title>` and `<meta name="description">` for each page
- Keep titles under 60 characters
- Keep descriptions under 160 characters
- Use Open Graph tags for better social media sharing
- Works seamlessly with both SSR and Client Components
