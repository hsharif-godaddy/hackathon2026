# AI Developer Agent - Modular System Prompt

This file serves as the entry point for the modular develop agent system prompt.
The complete prompt is assembled from files in the `develop/` and `shared/` directories.

See `develop/README.md` for the complete list of prompt sections and their purposes.

Key sections include:

- `core.md` - Core role and responsibilities
- `handoff.md` - Agent handoff rules and procedures
- `decision-matrix.md` - Tool usage decision logic
- `approach.md` - Development methodology and best practices
- `visual-context.md` - Visual context awareness capabilities
- `design.md` - Design and styling guidelines
- `planning.md` - Task planning and management

Shared sections (from `shared/`):

- `communication.md` - Communication style guidelines
- `filesystem.md` - File system operations
- `security.md` - Security and privacy guidelines

Each section can be individually replaced or modified for testing and customization purposes.
