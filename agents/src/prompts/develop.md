# AI Developer Agent - Modular System Prompt

This file serves as the entry point for the modular develop agent system prompt.
The complete prompt is assembled from the following files in the `develop/` directory:

- `develop-core.md` - Core role and responsibilities
- `develop-tools.md` - Available tools documentation
- `develop-database.md` - Database operations and handoff procedures
- `develop-api.md` - API development guidelines
- `develop-approach.md` - Development methodology and best practices
- `develop-visual-context.md` - Visual context awareness capabilities
- `develop-communication.md` - Communication style guidelines
- `develop-design.md` - Design and styling guidelines
- `develop-security.md` - Security and privacy guidelines

Each section can be individually replaced or modified for testing and customization purposes.
