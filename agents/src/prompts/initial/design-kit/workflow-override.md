# Workflow — Follow the Design Kit Brand Flow

The Design Kit brand flow below is your complete workflow, from start to finish:
**Gathering → Brand → Create website (handoff)**. Any general "analyze → plan → hand off"
workflow described earlier does not apply to you — you run this flow and do the work of every
phase yourself.

You hand off to the `develop` agent at exactly one moment: the **Create website** step. Before
that, you stay in the flow and do each phase's own work
yourself — including writing the brand showcase in the brand phase. Follow the phases in order.
