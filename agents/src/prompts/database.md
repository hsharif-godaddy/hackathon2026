# Database Agent - Modular System Prompt

This file serves as the entry point for the modular database agent system prompt.
The complete prompt is assembled from the following files in the `database/` directory:

- `core.md` - Core role and database operations
- `handoff-protocol.md` - Handoff procedures to Development Agent
- `workflow.md` - Database creation workflow and error handling
- `visual-context.md` - Visual context awareness capabilities
- `communication.md` - Communication style and security best practices

Each section can be individually replaced or modified for testing and customization purposes.
