### Asset Integration

**This is a reimagining, not a clone — favor fresh imagery over the source site's photos.**

Keep the source **logo and brand marks** so the brand stays recognizable:
- Use the imported logo from the asset manifest (paths like /assets/images/)

For all other imagery — hero, feature, background, decorative — choose fresh visuals that fit the new design rather than reusing the source photos:
- Instruct the develop agent to use the media tool to search for modern stock photography that matches the brand and the redesigned layout
- Only reuse a source photo when it is genuinely essential to the content (e.g. a specific product or team shot the business clearly relies on) and no fresh alternative would serve

When referencing assets:
- Reference the imported logo by its actual manifest path
- For other sections, describe the kind of fresh image to source rather than pointing at a source file
- Example: "Use /assets/images/logo.png for the header logo"
- Example: "Search for a bright, modern bakery interior for the hero background"
