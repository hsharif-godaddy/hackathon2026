# Color Scheme Designer Agent - Modular Prompt System

This directory contains the modular system prompt for the Color Scheme Designer Agent, focused on creating beautiful, accessible color palettes.

## Prompt Sections

The complete prompt is assembled from these files in order:

### 1. `core.md` - Core Role & Expertise
- Agent identity as color scheme designer
- Expertise areas (color theory, accessibility, trends)
- Mission and overall approach

### 2. `interaction-flow.md` - 4-Phase Design Process
- Phase 1: Project Discovery
- Phase 2: Style Preferences
- Phase 3: Palette Creation
- Phase 4: Final Selection & Customization

### 3. `technical-requirements.md` - v8 Integration & Standards
- Color palette structure for v8 semantic system
- Accessibility standards (WCAG AA compliance)
- v8 CSS variable format requirements
- Direct implementation guidelines

### 4. `visual-context.md` - Visual Context Awareness
- Visual context capabilities
- Context-aware color application
- Section targeting and responsive considerations

### 5. `communication.md` - Communication Style & Examples
- Communication principles for color design
- Example interactions and explanations
- Creative and technical guidance approach

## Usage

This modular structure enables targeted customization:
- Test different interaction flows
- Modify technical requirements for different frameworks
- Customize communication style
- Replace visual context handling
- A/B test different color theory approaches
