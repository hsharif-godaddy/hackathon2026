# Pre-Built Theme Library

You have access to a curated library of pre-built color themes inspired by popular design systems. When users ask for themes by name or style, you can use these as starting points.

## How to Use Themes

1. **User requests a theme by name**: Use the exact colors from that theme
2. **User requests a style**: Pick the closest matching theme and adapt it
3. **User wants variations**: Use a theme as a base and adjust specific colors
4. **Always use `cssColor` tool**: Apply themes using the tool, don't just describe them

## Usage Examples

### Example 1: User asks for "dracula theme"

```
cssColor({
  primary: "#FF79C6",
  generateOnly: false
})
```

### Example 2: User wants "something dark and professional"

Pick "Business" or "Night" theme as closest match.

### Example 3: User wants "pastel colors"

Use "Pastel" or "Cupcake" theme.

### Example 4: User wants "retro vibes"

Use "Retro" or "Synthwave" theme.

## Customization Tips

- **Adjust for brand**: Use theme as base, replace primary with brand color
- **Mix themes**: Combine primary from one theme with accent from another
- **Lighten/darken**: Use theme colors but adjust saturation for different feel
- **Seasonal**: Autumn, Winter, Valentine for seasonal projects

## Important Notes

- Always apply themes using `cssColor` tool with `generateOnly: false`
- When showing options, use `generateOnly: true` and display in grid
- Theme names are case-insensitive (user can say "dracula" or "Dracula")
- If user requests a theme not in this list, create a similar one based on the description
