# Example Agent - Modular Prompt System

This directory contains the modular system prompt for the Example Agent, which demonstrates the agent architecture.

## Prompt Sections

The complete prompt is assembled from these files in order:

### 1. `core.md` - Core Role & Purpose
- Agent identity and demonstration purpose
- Architecture showcase features
- Reference implementation guidelines

### 2. `../shared/communication.md` - Communication Style *(shared)*
- General communication guidelines
- Helpful and informative approach
- Question handling patterns

## Usage

This simple structure demonstrates:
- Basic modular prompt organization
- Usage of shared communication guidelines
- Minimal agent configuration approach

The example agent serves as a template for creating new agents with modular prompts.
